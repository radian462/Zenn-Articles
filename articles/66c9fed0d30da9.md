# そもそもFletとは
Fletはフロントエンドの経験がなくても、簡単にGUIを作成できるフレームワークです。
FletのUIはFlutterをベースに構築されており、HTMLやJavaScriptなどの知識を必要とせずにモダンなUIのWeb、デスクトップ、モバイルアプリケーション作成できます。
Fletは言語に依存しないことを掲げており、現時点ではPythonのみですがGOやC#をサポートする予定されています。

現在、リポジトリのStarは14400を超えています。
https://github.com/flet-dev/flet


#  
FletはFilePickerを使ってファイルをアップロード/ダウンロードできるのですが、これはWebに対応していません。
じゃあどうすればいいのかと思い、ドキュメントを読んでみるとこんな記述を見つけました

https://flet.dev/docs/controls/filepicker/#save_file

>To save a file from the web, you don't need to use the FilePicker object.
>
>You can instead provides an API endpoint /download/:filename that returns the file content, and then use page.launch_url to open the url, which will trigger the browser's save file dialog.

どうやら、APIエンドポイントを立てるといいみたいです。

# エンドポイントを立てる。
エンドポイントを組み込んで、ボタンを押したらファイルをダウンロードするWebアプリを作ってみましょう。今回エンドポイントはfletの依存関係にあるFastAPIを使います。

ちなみにflet_fastapiは非推奨になっているためflet.fastapiを使います。`import flet.fastapi as flet_fastapi`とすればコードを書き換えずに使えます。

https://flet.dev/blog/flet-fastapi-and-async-api-improvements/

https://flet.dev/docs/publish/web/dynamic-website/#advanced-fastapi-scenarios


```python
import os

import flet as ft
import flet.fastapi as flet_fastapi
import uvicorn
from fastapi import FastAPI
from fastapi.responses import FileResponse


def main(page: ft.Page):
    page.title = "ファイルダウンロード"

    def on_button_click(e):
        print("Botton clicked")
        page.launch_url("/download/test.txt")

    button = ft.FilledTonalButton(
        "ダウンロード", icon=ft.Icons.DOWNLOAD, on_click=on_button_click
    )
    
    page.add(
        ft.Column(
            [
                ft.Row([button], alignment=ft.MainAxisAlignment.CENTER)
            ],
            alignment=ft.MainAxisAlignment.CENTER,
            expand=True,
        )
    )

app = FastAPI()


@app.get("/download/{filename}")
def download(filename: str):
    file_path = os.path.join("files", filename)
    return FileResponse(
        path=file_path,
        headers={"Content-Disposition": f'attachment; filename="{filename}"'},
    )


app.mount("/", flet_fastapi.app(main))

if "__main__" == __name__:
    os.makedirs("files", exist_ok=True)
    test_file = os.path.join("files", "test.txt")
    if not os.path.exists(test_file):
        with open(test_file, "w", encoding="utf-8") as f:
            f.write("This is a test file")

    uvicorn.run(app, host="0.0.0.0", port=8080)
```
